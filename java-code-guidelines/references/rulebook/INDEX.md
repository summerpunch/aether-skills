## 查找规则

先选章，再用小节和编号定位。例如 `一（六）14` 是编程规约的集合处理第 14 条。可搜索 `^##` 查看小节，搜索 `^### 14\.` 查看条目；若同一数字在不同小节重复，必须先限定小节。复合条款的强制/推荐等级按其内部标记判断。

## 使用边界

- 原规约的【强制】【推荐】【参考】属于原文等级；风险严重程度需另行判断。
- 正反例为理解规则服务，不能脱离上下文直接复制。尤其是旧 API、日志留存、异常边界、线程池和数据库约定，要结合目标项目核实。
- 这里是完整规约内容；`../java-implementation.md`、`../service-quality.md`、`../persistence-architecture.md` 是面向当前项目执行的补充说明，不替代正文。
